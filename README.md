# **Casual Org-Roam**

A suite of customizations for Org-Roam and Org-QL, designed to streamline your note-taking and knowledge management workflow. This package provides an interactive query builder, customizable keybindings, and a intuitive interface for exploring and navigating your Roam database.

**Features**

* Interactive Query Builder: Construct complex queries using Org-QL with an intuitive interface
* Customizable Keybindings: Modify or add keybindings to suit your workflow
* Dynamic Filters: Apply filters to your Roam database using Org-QL
* Visualizer: Open a graph view of your Roam database using Org-Roam Graph or Org-Roam
-UI
* Agenda Integration: Search and filter your Roam database based on due dates and deadlines

**Requirements**

* Emacs 28.1 or later
* Org-Roam 2.2.0 or later
* Org-QL 3.0.0 or later

**Installation**

1. Clone this repository into your Emacs package directory (`~/.emacs.d`)
2. Install the required packages using `M-x
 package-install`
3. Load the `casual-org-roam` package in your Emacs configuration file (`init.el`)

**Usage**

* Activate the `casual-org-roam` package using `M-x casual-org-roam-master`
* Explore the menu options and keybindings to discover the full range of features
* Construct queries using the interactive query builder to search and filter your Roam database
